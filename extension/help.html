EasyUnderstand · Video

Your video, explained.

Choose a model once

Open the EasyUnderstand desktop app, then Settings → YouTube analysis. Gemini 3.8 Flash is the default. Get an API key using the link in Settings, paste it into Video API key, click Save, then Test video model. The test sends a short sample transcript to verify access and citation structure. Video API usage is billed separately by the provider. Restart the desktop app after an update to see the new Settings.

Azure OpenAI: select the Azure GPT-6 Astra preset, enter your deployment name and full /openai/responses?api-version=… endpoint, then save the Azure resource key in Video API key. Use Test video model before opening a video. The Chat Completions demo uses a different API; this companion uses Responses.

Use it on YouTube

Open a video and click Understand video. The complete caption transcript is sent once. Read the overview and concrete Key takeaways, then open Explore the breakdown for compact explanations, examples and meaningful caveats. Expand Sources inside a theme for timestamp links and caption excerpts.

Copy summary + breakdown copies the current language's complete analysis, including collapsed themes and timestamp links, as Markdown you can paste elsewhere. It includes the video URL and model name, but not the raw transcript. Clipboard writing happens only when you click Copy.

The summary adapts to the video: lectures explain concepts and how they connect, tutorials explain methods, and discussions explain positions and their reasoning. Course introductions distinguish material taught now from topics planned for later, with logistics kept concise. Substantive closing lessons are preserved. When relevant, open Critical assessment for a separate model assessment of substantive claims: support offered, assumptions and limits, and evidence to check. Definitions and course objectives do not need a manufactured debate. This uses the transcript and logical analysis; external facts have not been checked. Critical assessment is included in the same model response, optional translation, and Copy output.

The timer measures your full wait, from clicking the button until the summary is ready to display, and keeps the final time in seconds to three decimal places. It shows Fresh model response with model request time, or Cached summary · No model call, without opening the details. Expand it to see panel opening, helper connection, transcript loading, model request, helper and transfer, and display times. Model time includes network waiting and checking the response. Helper and transfer covers the remaining request time, including preparation, cache access, and communication. Display includes rendering and waiting for the browser to paint. The panel reuses its helper connection for repeat summaries, translations, and questions. Use Summarize again for a fresh run to compare speed; it uses your video model again. Translation and questions do not change the summary timing or its source label.

Captured words and estimated tokens appear as soon as captions load and stay visible with the summary. They measure caption text only. Token counts are a rough local estimate, vary by model and language, and exclude the extra instructions sent with the captions.

Clear cache beside Understand video removes saved video summaries and translations and clears the current panel. It makes no model request. API keys, settings, and everyday translation history are kept. Your next summary is generated afresh.

Translate to Chinese translates the existing analysis using your everyday translation model and key. Ask the transcript uses the video model to answer follow-up questions from the original captions. Video and translation settings are independent.

If something goes wrong

Cannot connect: run npm run setup:youtube from your EasyUnderstand checkout, then reload the extension and YouTube. Keep the checkout in place.

Error after reloading the extension: refresh the existing YouTube tab once to replace its old extension script. If the button says Reload YouTube to reconnect, clicking it refreshes the tab for you.

Missing captions: check whether YouTube’s Show transcript button is available. The companion never substitutes the video description as evidence.

Model error: check the video model and key in Settings. Providers can block content or hit quota limits. The Alibaba/Qwen provider blocked the political interview excerpt during testing.

Captions can contain errors and omit visual information. Analysis can miss or misinterpret a point; citation links let you inspect the original text. Completed analyses are cached locally for 7 days, with at most 30 saved entries. English and Chinese entries share this limit; the oldest are deleted first. Reopening a summary does not extend its lifetime. Expired entries are never reused; cleanup runs on app startup, hourly while the app runs, and when using the video helper. Use the desktop tray’s Open data folder action to inspect or remove video-cache.
